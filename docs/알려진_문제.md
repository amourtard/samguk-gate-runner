# 알려진 문제

플레이와 시험 중 발견했지만 아직 고치지 않은 것을 적는다. 수치 조정은 플레이한 사람이 정한 뒤에 반영한다.

## 밸런스

### 보스를 만나면 대부분 그냥 이긴다 (단계 5, 1차 조정함)

- **상태**: 2026-11-12에 한 방 피해 상한과 보스 체력 조정으로 보스전이 15~21초, 예고 3~4번이 되었다(자동 플레이 기준, 진행기록 참고). 사람이 플레이한 뒤 다시 본다. 아래는 고치기 전 기록이다.

- **현상**: 보스 장각이 첫 공격 예고를 띄우기 전에 쓰러지는 판이 많다. 자동 시험에서 시작 병력이 많은 판은 예고가 한 번도 나오지 않았다.
- **원인**
  - 보스가 주는 손실은 예고 구역 공격(병력 25%, 피하면 0)과 접촉 중 초당 2명뿐이다. 일반 적처럼 초당 피해를 주지 않는다.
  - 마지막 책략 지점에서 보스까지 30m라 약 4초면 닿는데, 첫 예고는 패턴이 켜지고 5초 뒤에 시작한다.
  - 보스 체력(1-1 400 ~ 1-5 1,500)에 비해 아군 화력이 크다. 기병 돌격은 병력 × 8이라 50명이면 닿는 순간 400을 준다. 궁병은 12m 밖에서 초당 최대 120을 준다. 선봉, 화계, 정병이 붙으면 더 빨라진다.
- **조정 후보** (모두 데이터 파일 수정)
  - `stages.json`의 `boss_health` 올리기
  - `tuning.json`에 첫 예고까지의 시간을 따로 두고 앞당기기
  - `tuning.json`의 `boss.contact_loss_per_second` 올리기
  - 보스에게 들어가는 돌격과 화계 배율을 따로 두기 (명세에 없는 규칙이 하나 늘어난다)
- **상태**: 플레이 후 방향을 정하기로 함

### 외부 검토 의견 (2026-11-12, 대부분 반영)

사람이 넣어 준 검토 의견을 코드와 자동 플레이 기록에 대조했다. 작업지시 (25)로 반영했다(진행기록 "외부 검토 의견 반영"). 남은 것은 초반 교전 길이(적 수를 늘려도 접촉 후 0.0~0.9초)와 전환 게이트의 장수 개성(손대지 않음)이다.

| 의견 | 대조 결과 |
| --- | --- |
| 장비의 철벽 호령이 보스전에서 작동하지 않는다 | 맞다. 보스 공격은 `army.lose_soldiers()`로 병력을 바로 깎아 `damage_taken_mult`를 보지 않는다. 같은 이유로 철갑 책략과 방어 강화 게이트도 보스 공격에는 효과가 없다 |
| 병력이 많으면 불덩이를 피할 수 없다 | 일부 맞다. 1초 안에 4.6m는 옮길 수 있다(좌우 속도 12m/s). 그러나 무리 반폭이 3m쯤이면 구역 예고 중에 안전한 반쪽 안에서 불덩이를 피할 자리가 없다. 명세의 "보스전에서 피할 수 없는 손실은 없다"가 큰 무리에서는 지켜지지 않는다 |
| 연환은 혼자 뽑으면 효과가 없다 | 맞다. 지속 피해는 불화살이 있어야 생긴다. 자동 플레이 45판에서 연환을 가진 판의 돌파율이 55%로 가장 낮았다 |
| 초반 교전이 너무 짧다 | 맞다. 자동 플레이 기록에서 1구간의 접촉 후 교전 시간 중앙값이 0.0초다 |
| 먼 산 그림 아래가 수평으로 잘려 보인다 | 맞다(A1_달리기). 그림 아래쪽을 안개 색으로 흐리면 된다. 의견에 적힌 파일 이름(road_view.gd)은 틀렸고 `field_view.gd`다 |
| 번개가 노란 막대로 보인다 | 맞다. `boss_view.gd`의 상자 기둥이다. lightning.png는 아직 쓰지 않았다 |
| 분노 때 구역 예고와 불덩이 예고가 같은 붉은색이라 겹친다 | 맞다(B3_불덩이_예고) |
| 장수와 다른 병종으로 전환하면 장수 개성이 흐려진다 | 취향의 문제다. 전환 게이트는 상성 대응 수단이라 없애면 규칙이 바뀐다 |
| 깃발 글자와 숫자가 겹친다, 판에 패널 그림을 입히자 | 깃발은 (22)에서 이름 전체로 바꿨다. 패널 그림은 쓰지 않은 상태다 |

## 동작

### 병종 전환 게이트가 지금과 같은 병종으로 나올 수 있다 (단계 5, 해결)

- **상태**: 2026-11-11 해결. 대상이 아군 병종과 같으면 다른 병종으로 바꾼다(명세 3장). 아래는 고치기 전 기록이다.

- 게이트는 판 시작 때 무작위로 만들어지고, 그때는 통과 시점의 아군 병종을 알 수 없다.
- 같은 병종이면 병종은 그대로이고 병력만 20% 줄어서 사실상 함정이 된다.

### 세 번째 책략은 보스전에만 영향을 준다 (단계 4, 5, 해결)

- **상태**: 2026-11-11 해결. 책략 세 개를 모두 출전 직전에 고른다. 아래는 고치기 전 기록이다.

- 기획서대로 책략은 구간이 끝날 때 고른다. 세 번째 선택 뒤에는 보스전만 남는다.
- 보스전이 짧아서(위 보스 문제) 세 번째 책략의 효과를 체감하기 어렵다.

### 함정 게이트 금화가 아직 지급되지 않는다 (단계 3, 해결)

- **상태**: 2026-11-11 단계 6에서 해결. 아래는 고치기 전 기록이다.

- 판 중에 모은 금액은 화면 아래에만 표시된다. 금화 지급과 저장은 단계 6 작업이다.

### 진행 상황이 저장되지 않는다 (단계 5, 해결)

- **상태**: 2026-11-11 단계 6에서 해결. 아래는 고치기 전 기록이다.

- 열린 스테이지와 고른 장수는 메모리에만 있어서 게임을 끄면 1-1부터 다시 시작한다. 저장은 단계 6 작업이다.

### 장수 선택 화면이 스테이지 줄이 늘면 넘친다 (단계 6, 해결)

- **상태**: 2026-11-11 해결. 스테이지 버튼을 한 줄로 놓고 좌우로 밀어서 고르게 했다. 왼쪽에 스테이지가 더 있다는 표시는 없다. 아래는 고치기 전 기록이다.

- 스테이지 버튼이 한 줄(1-1~1-5)일 때는 화면에 다 들어간다. 1-6 이후가 열려 둘째 줄이 생기면 세로로 넘쳐 제목이 화면 위로 밀린다.
- 고치려면 스테이지 영역을 스크롤로 바꾸거나 최근 스테이지만 보여줘야 한다.

### 저장을 지우는 화면이 없다 (단계 6)

- 처음부터 다시 하려면 저장 파일(user://save.json)을 직접 지워야 한다. 윈도우에서는 `%APPDATA%\Godot\app_userdata\삼국지 게이트 러너\save.json`이다. 코드에는 `GameState.reset_game()`이 있지만 부르는 버튼이 없다.

## 렌더링

### Compatibility 렌더러에서 병사가 검게 나온다 (단계 V1, 우회함)

- **현상**: 병사 MultiMesh에 흔들림 박자용 인스턴스 사용자 데이터(`use_custom_data`)만 켜고 인스턴스 색(`use_colors`)을 끄면, Compatibility 렌더러에서 병사의 꼭짓점 색이 검게 나왔다.
- **원인(추정)**: Compatibility 렌더러가 인스턴스 색 속성이 없을 때 셰이더의 `COLOR`(꼭짓점 색)에 흰색이 아닌 값을 곱하는 것으로 보인다. 엔진 소스나 이슈로 확인하지는 않았다.
- **우회**: `scripts/army_view.gd`에서 `use_colors`를 켜고 모든 병사에 흰색 인스턴스 색을 넣는다. 흰색을 곱하므로 색은 바뀌지 않는다. 병사가 다시 검게 나오면 이 설정이 빠졌는지 먼저 본다.
- **상태**: 우회로 해결. 엔진을 올릴 때 우회 없이도 정상인지 확인할 수 있다.

## 개발 환경

### 헤드리스 실행 종료 시 오디오 경고가 나온다 (단계 3)

- `--headless`로 실행하고 종료하면 "ObjectDB instances were leaked", "resources still in use" 경고가 나온다.
- 소리 하나만 재생하고 멈춘 뒤 해제하는 최소 예제에서도 똑같이 나와서, 헤드리스 모드의 오디오 처리에서 생기는 엔진 쪽 현상으로 판단했다. 스크립트 오류는 아니다.

### 효과음이 직접 합성한 임시 소리다 (단계 3)

- 명세는 무료 공개 음원이지만, 라이선스 확인을 피하려고 짧은 소리를 직접 합성했다.
- `audio/`의 `gate.wav`, `arrow.wav`, `hit.wav`를 같은 이름으로 바꾸면 그대로 쓰인다.

### 새로 넣은 그림은 에디터를 한 번 열어야 보인다

- **상태**: 2026-11-12 기록. 사람이 PC에서 에디터를 열면 해결된다.
- `assets/ui`, `assets/strategies`, `assets/env`, `assets/particles`의 새 PNG에 `.import` 파일이 없다(2026-11-12 확인. 소리와 모델에는 있다). 가져오기 전에는 게임이 전의 모양(민무늬 버튼, 계열 아이콘, 잡음 무늬 바닥, 그라데이션 하늘)으로 돈다.
- Godot 프로젝트 매니저에서 "편집"으로 한 번 열면 가져온다.

### 조달했지만 쓰지 않은 자원

- `assets/particles/lightning.png`, `assets/ui/panel_wood.png`, `assets/ui/panel_metal.png`, `assets/ui/result_bg.png`(패배 배경과 같은 파일). 쓰려면 작업 지시가 필요하다.
