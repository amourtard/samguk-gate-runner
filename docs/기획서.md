# 삼국지 게이트 러너 기획서

Nov 10, 2026 · @승환

## 1. 개요

게이트를 골라 병력을 불리며 적진을 돌파하는 삼국지 러너에, 판마다 달라지는 책략 선택과 장수 수집을 붙인 싱글플레이 모바일 게임이다. 먼저 2주짜리 프로토타입으로 30판째에도 재미있는지를 확인하고, 통과했을 때만 본 개발로 넘어간다.

| 항목 | 내용 |
| --- | --- |
| 가제 | 삼국지 게이트 러너 (정식 제목 미정) |
| 장르 | 게이트 러너 + 로그라이크 + 수집형 성장 |
| 플랫폼 | 안드로이드 우선, 이후 iOS |
| 엔진 | Godot |
| 개발 체제 | 1인 개발, 서버 없는 싱글플레이 |
| 한 판 길이 | 2\~3분 |
| 수익 모델 | 보상형 광고 + 소액 인앱 |
| 1차 목표 | 2주 프로토타입으로 재미 검증 |

## 2. 시장 근거와 차별점

게이트 러너는 광고에서 가장 잘 먹히는 문법인데, 정작 이 재미를 본편으로 깊게 만든 게임은 드물다. 그 빈자리가 이 기획의 자리다.

- **유입력은 검증됨**: 2026년 11월 1주 모바일인덱스 주간 매출 18위인 탑 로드를 비롯해 대형 전략 게임들이 이 러너를 광고와 초반 미끼로 쓴다. 본편은 연맹 전쟁 게임이라 "광고와 다르다"는 불만이 나온다.
- **기존 러너의 한계**: 숫자 큰 게이트가 항상 정답이라 선택이 없고, 10분이면 바닥난다.
- **풀린 적 있는 문제**: 갤러그식 단순 슈팅이 뱀파이어 서바이버즈, 탕탕특공대로 살아난 방식이 판마다 다른 빌드와 판 밖의 영구 성장이다. 같은 처방을 러너에 쓴다.

| 구분 | 기존 게이트 러너 | 이 게임 |
| --- | --- | --- |
| 게이트 | 큰 숫자가 정답 | 수량과 병종, 능력이 충돌하는 딜레마 |
| 판마다 차이 | 거의 없음 | 책략 3택으로 빌드가 달라짐 |
| 장기 목표 | 없음 | 장수 수집과 영구 강화 |
| 본편과 광고 | 다름 | 광고에 나온 그 게임이 본편 |

## 3. 코어 루프

한 판은 2\~3분이고, 좌우 드래그 하나로 조작한다. 공격은 자동이다.

**한 판의 흐름**

1. 장수 1명과 소수 병력으로 출발한다.
2. 좌우 두 게이트 중 하나를 골라 통과한다. 한 구간에 게이트는 2\~3번 나온다. 병력 수, 병종, 능력이 바뀐다.
3. 적 무리와 장애물을 돌파한다. 병력이 닿으면 서로 깎인다.
4. 구간 끝에서 책략 3개 중 1개를 고른다.
5. 2\~4를 3구간 반복한다.
6. 적장(보스)과 싸운다.
7. 결과에 따라 금화와 장수 조각을 받는다.

**판 사이의 흐름**

1. 받은 보상으로 장수를 강화하거나 새 장수를 영입한다.
2. 영구 강화(병영, 무기고 등)를 올린다.
3. 다음 스테이지에 도전한다. 막히면 성장해서 다시 온다.

## 4. 전투 시스템

게이트마다 정답이 달라지게 만드는 것이 전투 설계의 전부다. 수량, 병종, 능력 세 축이 서로 충돌해야 한다.

**게이트 종류**

| 종류 | 예시 | 고민거리 |
| --- | --- | --- |
| 증원 | +20명, ×2 | 지금 병력이 적을수록 덧셈이, 많을수록 곱셈이 유리 |
| 병종 전환 | 전원 궁병으로 | 다음 구간 적 구성에 맞는가 |
| 강화 | 공격속도 +50%, 방어 +30% | 수를 포기하고 질을 올릴 것인가 |
| 도박 | 50% 확률로 ×3 또는 ÷2 | 지고 있을 때의 역전 수단 |
| 함정 | −30명 대신 보물 상자 | 이번 판을 희생해 영구 보상을 얻을 것인가 |

**병종 상성**

| 병종 | 강점 | 약점 |
| --- | --- | --- |
| 보병 | 수가 많고 창으로 기병 돌격을 받아냄 | 궁병에게 접근 전에 깎임 |
| 궁병 | 원거리, 보병에 강함 | 기병 돌격에 약함 |
| 기병 | 돌파력, 궁병에 강함 | 밀집한 보병과 장애물에 약함 |

다음 구간의 적 구성을 화면 위쪽에 미리 보여준다. 정보를 보고 고르는 선택이어야 운이 아니라 판단이 된다.

**교전 방식**

병력이 닿는 순간 숫자끼리 빼는 것으로 보이면 안 된다. 궁병은 닿기 전에 먼저 쏘고, 기병은 빠르게 거리를 좁혀 들이받고, 보병은 맞붙어 버틴다. 상성은 수치 보정이 아니라 이 교전 순서에서 눈에 보이게 나온다.

**상성 게이트의 대가**

적 구성을 미리 보여주면 상성에 맞는 병종 전환이 뻔한 정답이 된다. 그래서 병종 전환과 강화 게이트에는 병력 감소 같은 대가를 붙이고, 적 구성은 한 병종으로 몰지 않고 섞는다. 예: 적이 궁병 60%, 보병 40%일 때 "+25명 보병"과 "기병 전환, 병력 −30%".

**게이트 가독성**

달리면서 1초 안에 읽혀야 한다. 종류마다 색을 고정하고(증원 파랑, 강화 빨강, 병종 전환 초록, 도박 보라, 함정 회색), 아이콘과 큰 숫자를 쓰며, 대가가 있으면 같은 판 안에 작게 함께 적는다.

게이트 직전 약 0.5초 동안 이동 속도를 절반으로 늦춰 읽을 시간을 준다. 속도감이 죽을 수 있으므로 프로토타입에서 켠 판과 끈 판을 비교해 정한다.

**병력 표시 방식**

병력 수와 전투 결과는 숫자로 계산하고, 화면의 병사는 그 숫자를 보여주는 표현으로 분리한다. 150\~200명까지는 실제 수만큼 그리고(Godot MultiMesh), 그 이상은 일정 비율로 묶어 표시한다. 무리가 불어나는 모습이 재미의 핵심이라 처음부터 30개 안팎으로 묶지는 않는다. 실제 상한은 프로토타입을 폰에서 돌려 프레임을 보고 정한다.

**보스와 기믹**

- **적장**: 숫자만으로 안 밀리는 패턴을 하나씩 가진다. 예: 여포는 일정 시간마다 전방 일직선을 쓸어버려 좌우로 피해야 한다.
- **지형**: 좁은 다리(병력이 많으면 손해), 화공 구간(계속 깎임), 성문(공성 능력이 없으면 오래 걸림).

## 5. 책략 선택 (로그라이크)

구간이 끝날 때마다 책략 3개 중 1개를 고르고, 한 판에 3번 고른다. 같은 스테이지도 책략 조합에 따라 다르게 풀리게 하는 장치다.

| 계열 | 예시 | 어울리는 빌드 |
| --- | --- | --- |
| 물량 | 증원 게이트 효과 +50% | 보병 인해전술 |
| 정예 | 병력 절반, 개별 능력 3배 | 소수 기병 돌파 |
| 화공 | 화살에 불 붙음, 지속 피해 | 궁병 원거리 |
| 계략 | 다음 게이트 3개 미리 보기 | 도박 게이트 활용 |
| 장수 | 장수 고유 기술 재사용 시간 감소 | 장수 중심 |

- 같은 계열을 2개 이상 모으면 추가 효과가 붙는다. 한 방향으로 밀지 섞을지가 고민이 된다.
- 출시 시점 목표는 30종 안팎이다. 프로토타입은 물량, 정예, 화공 3계열 9종으로 시작한다(프로토타입 명세 탭).

책략을 고르면 병력이 눈에 띄게 달라져야 한다. 다만 책략마다 연출을 만들지 않고 계열 5개 단위로 색, 오라, 투사체만 바꾼다. 예: 화공 계열은 화살이 불화살로 바뀐다. 프로토타입에서는 병사 색 변화까지만 넣는다.

## 6. 메타 성장

판이 끝나도 남는 성장은 장수, 영구 강화, 스테이지 진행 세 가지로 한정한다. 1인 운영이 가능한 범위를 넘기지 않기 위해서다.

- **장수**: 출전 장수 1명이 시작 병종과 고유 기술을 정한다. 예: 관우는 기병으로 출발하고 일직선 돌격 기술을 쓴다. 조각을 모아 영입하고 등급을 올린다. 출시 목표 20명, 프로토타입 3명. 고유 기술은 프로토타입에서 게이지가 차면 자동 발동하고, 탭으로 직접 쓰는 방식은 알파에서 한 손 조작과 충돌하지 않는지 보고 정한다.
- **영구 강화**: 병영(시작 병력), 무기고(기본 공격력), 군량(금화 획득량) 같은 시설을 금화로 올린다.
- **스테이지**: 황건적 토벌에서 시작해 연의 순서로 장을 연다. 장마다 적 병종 구성과 지형이 달라진다. 출시 목표 5장 50스테이지.
- **넣지 않는 것**: 연맹, 실시간 대전, 순위 서버, 장비 강화 확률. 서버와 운영 인력이 필요한 요소는 모두 뺀다.

삼국지 소재 자체는 자유롭게 쓸 수 있지만, 기존 삼국지 게임의 장수 일러스트나 능력치 구성은 참고하지 않고 새로 만든다.

## 7. 수익 모델

보상형 광고를 기본으로 하고, 인앱은 소액 상품 몇 개만 둔다. 결제 없이 끝까지 깰 수 있어야 한다.

| 수단 | 내용 | 비고 |
| --- | --- | --- |
| 보상형 광고 | 패배 시 1회 부활, 보상 2배, 책략 다시 뽑기 | 주 수익원. 강제 광고는 넣지 않음 |
| 광고 제거 | 보상형 광고를 시청 없이 받기 | 1회 구매 |
| 성장 패키지 | 장 클리어 시 열리는 금화와 조각 묶음 | 장마다 1회 한정 |
| 월정액 | 매일 금화와 조각 지급 | 출시 후 반응을 보고 결정 |

- 확률형 뽑기는 넣지 않는다. 확률 표시 의무와 운영 부담이 1인에게 무겁다.
- 가격과 예상 매출은 프로토타입 통과 후에 정한다. 지금은 근거가 없다.

**유사 게임에서 확인한 것**

- 광고 제거를 월 구독으로 판 디펜스 게임(Last Legion)은 그 점이 리뷰 불만 1순위다. 광고 제거는 1회 구매를 유지한다.
- 다음 스테이지로 가려면 반드시 깨야 하는 반복 모드를 둔 게임(Mythic Survivors)은 귀찮다는 불만을 받는다. 진행을 막는 강제 숙제는 넣지 않는다.

## 8. 2주 프로토타입 범위

프로토타입은 "게이트 딜레마와 책략 선택이 30판째에도 재미있는가" 하나만 확인한다. 그 질문과 무관한 것은 전부 뺀다. 기간은 2주로 못 박고 연장하지 않는다.

| 넣는 것 | 빼는 것 |
| --- | --- |
| 좌우 드래그 이동, 자동 공격 | 그래픽 (도형과 색으로 대체) |
| 게이트 5종, 색과 아이콘으로 종류 구분 | 배경음, 컷신, 화려한 연출 |
| 최소 손맛: 효과음 3종(게이트 통과, 화살, 타격), 숫자 팝업 확대, 충돌 시 짧은 화면 흔들림, 궁병 선제 사격, 게이트 앞 감속(켜고 끄며 비교) | 장수 수집, 조각, 등급 |
| 병종 3종과 상성 | 광고, 결제 |
| 책략 9종, 구간마다 3택 | 스토리, 튜토리얼 |
| 책략 선택 기록 (로컬 파일) | 저장 (영구 강화 수치만 파일로) |
| 장수 3명 (시작 병종과 기술만 다름) | 스토어 등록 |
| 스테이지 5개와 보스 1종 | 책략별 외형 변화 |
| 영구 강화 2종 |  |
| 병력 표시 상한 측정 (실제 폰) |  |

**일정**

| 기간 | 작업 | 끝났을 때 상태 |
| --- | --- | --- |
| 1\~3일차 | 러너 이동, 병력 군집, 적 충돌 | 게이트 없이 달리고 싸우는 판이 돈다 |
| 4\~5일차 | 게이트 5종(색과 아이콘 구분), 병종 3종과 상성, 효과음과 숫자 팝업 | 게이트 선택에 따라 결과가 달라진다 |
| 6\~7일차 | 책략 9종, 3택 화면, 선택 기록 | 한 판이 처음부터 끝까지 이어진다 |
| 8\~9일차 | 스테이지 5개, 보스, 장수 3명 | 5스테이지를 순서대로 깰 수 있다 |
| 10일차 | 영구 강화 2종, 수치 저장 | 판 사이 성장이 돈다 |
| 11\~14일차 | 밸런스 조정, 본인과 지인 플레이 | 검증 기준을 판정한다 |

## 9. 검증 기준

14일차에 아래 기준으로 계속할지 멈출지를 정한다. 기준은 만들기 전에 정해둬야 만든 뒤에 스스로를 속이지 않는다.

- [ ] 본인이 숙제가 아니라 하고 싶어서 3일 이상, 합계 30판 이상 했다.
- [ ] 30판째에도 게이트 앞에서 고민한 순간이 있었다.
- [ ] 서로 다른 책략 빌드 3가지 이상으로 같은 스테이지를 깼다.
- [ ] 지인 3\~5명 중 절반 이상이 시키지 않았는데 다음 날 다시 켰다.
- [ ] "한 판만 더"가 나온 지점을 구체적으로 말할 수 있다.

| 결과 | 판단 |
| --- | --- |
| 4개 이상 충족 | 본 개발 진행. 삼국지 디펜스와 둘 중 주력을 정한다 |
| 2\~3개 충족 | 가장 약한 축 하나만 고쳐서 1주 더 본다. 한 번만 |
| 1개 이하 | 중단. 배운 점을 기록하고 디펜스로 돌아간다 |

책략 선택 기록으로 특정 책략 쏠림을 함께 본다. 재도전율, 평균 판 시간 같은 비율 지표는 표본 3\~5명으로는 의미가 없어 소프트 런칭 단계에서 측정한다.

## 10. 이후 로드맵과 리스크

프로토타입을 통과하면 약 4\~5개월 뒤 한국 안드로이드 출시를 목표로 한다. 기간은 퇴근 후 작업 기준의 추정이고, 프로토타입에서 실제 속도를 본 뒤 다시 잡는다.

| 단계 | 기간 | 내용 |
| --- | --- | --- |
| 프로토타입 | 2주 | 재미 검증 |
| 알파 | 2개월 | 그래픽 적용, 연출 강화, 장수 10명, 책략 20종, 2장 20스테이지, 저장 |
| 베타 | 1.5개월 | 장수 20명, 5장 50스테이지, 광고와 결제 연동, 튜토리얼 |
| 소프트 런칭 | 1개월 | 구글 플레이 공개 테스트, 잔존율, 패배 후 재도전율, 평균 판 시간, 광고 시청률 측정 |
| 정식 출시 | 이후 | 지표가 나오면 iOS, 소액 광고 테스트 |

**알파의 연출 강화**

프로토타입은 최소 손맛만 넣고, 화려한 연출은 재미가 확인된 뒤 알파에서 붙인다. 이 게임의 주인공은 병력 수이므로 피해 숫자와 이펙트가 병력 숫자와 게이트를 가리면 안 된다.

- **터뜨리는 순간을 한정한다**: 장수 고유 기술, 책략 계열 효과 발동, 보스 격파와 대량 처치. 이때만 피해 숫자 다발과 큰 범위 이펙트를 쓴다.
- **평소 교전은 절제한다**: 피해 숫자는 작고 적게 띄운다. 게이트 앞 구간에서는 이펙트를 줄인다.
- **숫자 단위를 키운다**: 내부 계산은 그대로 두고 표시 수치에 100을 곱해 수백\~수천 단위로 보이게 한다.
- **성능 상한을 둔다**: 숫자 표시는 재사용(풀링)하고 파티클 수에 상한을 둔다. 병사 200개와 겹쳐도 프레임이 유지되는지 폰에서 확인한다.
- **글자를 데이터 파일로 분리한다**: 텍스트가 적은 장르라 다국어 확장이 쉽다. 알파에서 분리해 둔다.
